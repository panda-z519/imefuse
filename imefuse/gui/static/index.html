imefuse

三家 macOS 输入法个人词频互通 · 合并导入，永不覆盖

① 导出

把某个输入法的个人词频导出成 canonical 文件（JSONL + TSV）。只读，不改任何数据。

② 合并导入

选目标输入法和一份导出文件，先看 diff（新增 / 累加 / 同词异音），确认后才会写入。写入前自动备份、自动退出输入法、写完自动重启。

③ 一键迁移

选源和目标，直接把源的个人词迁移到目标（内部就是「导出 → 合并导入」，同样先看 diff 再落盘）。
